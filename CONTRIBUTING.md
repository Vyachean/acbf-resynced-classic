# Contributing

At this stage the project is **owner-maintained and research-first**.

## Helpful contributions

You are welcome to open an issue with:

- Precisely reproducible differences between original AC4 and Resynced controls.
- Exact game build, input device, loaded mods, and step-by-step reproduction.
- Public technical documentation, relevant original research, and evidence-backed observations.
- Focused logs or debug output requested by a maintainer, **after sanitizing personal information**.

Use the [bug report](.github/ISSUE_TEMPLATE/bug_report.yml) or [research request](.github/ISSUE_TEMPLATE/research.yml) templates.

## Code contributions are not automatically licensed

This is a **proprietary, all-rights-reserved** project, **not** a permissively licensed or open-source project. Please **do not submit code pull requests without discussing terms with the owner first**. Any accepted code contribution requires mutually agreed written permission sufficient for the owner to use and distribute it; an issue or PR by itself is not a copyright assignment.

Do not copy code from other projects solely because it is visible on GitHub. Respect all third-party licenses. Do not upload game executables, copyrighted game assets, proprietary SDK files, cracked executables, credentials, or personally identifying log content.

## Research quality

- Label **observed**, **independently verified**, **hypothesis**, and **unknown** distinctly.
- Cite links to source documentation and note game versions and dates where relevant.
- Prefer minimal reproducible scenarios to speculative claims.
- Avoid attaching large memory dumps; prefer small, sanitized structured logs.

## Project expectations

Our immediate target is contextual input behavior, not a wholesale restoration of AC4 gameplay. Development priorities and acceptance criteria are in [ROADMAP](docs/ROADMAP.md) and [TESTING](docs/TESTING.md).
